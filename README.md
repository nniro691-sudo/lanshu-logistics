# 蓝枢 · 智慧物流

明亮毛玻璃风格的物流数字孪生演示网站，使用原生 HTML、CSS、JavaScript，无需安装依赖。

## 功能

- 运营总览：仓储场景、固定路线包裹输送、右侧卡车倒车入库与驶离动画。
- 车辆进出动态：进出记录与场景动画状态联动，点击可查看车辆。
- 运输车辆：透明卡车侧向驶入，车厢包裹可点击查看详情。
- 仓储管理、货箱档案与流转追踪。
- 自适应桌面与手机布局，支持减少动态效果的系统偏好。

所有业务数据均为演示数据。场景和设备使用生成的渲染素材，动画为前端演示，未连接实际物流系统。

## 本地预览

```sh
python3 -m http.server 5173 --directory dist
```

打开 http://localhost:5173。

## 发布

推送到 `main` 后，GitHub Actions 自动将 `dist` 发布至 GitHub Pages。
